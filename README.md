## 🌾 Overview

**B.S. Organic Manure** provides agricultural producers, horticulturists, and home gardeners with high-grade, aged organic manure enriched with essential macronutrients (Nitrogen, Phosphorus, Potassium) and beneficial soil microbes.

This web application serves as the primary commercial digital storefront, providing:
- Detailed breakdown of organic soil conditioners and nutrient profiles.
- Transparent packaging, bulk tier pricing, and logistics options.
- Direct customer inquiry and order placement integration.
- Responsive modern design optimized for mobile and desktop farm managers.

---

## 📑 Page Structure

- **`index.html`** — Primary commercial landing page:
  - Hero introduction with core value propositions.
  - Soil health benefits and comparative organic vs. chemical impact analysis.
  - Product specifications, moisture control benchmarks, and microbial vitality.
  - Transparent pricing tiers, customer testimonials, and direct WhatsApp / contact inquiry.
- **`privacy.html`** — Comprehensive privacy policy, customer data protection terms, and delivery guidelines.

## 🚀 Local Development & Preview

No complex build steps required — pure vanilla web stack for maximum performance and lightning-fast load times.

### Quick Preview
```bash
# Clone the repository
git clone https://github.com/Vaibhav007-star/B.S-Organic-Manure.git
cd B.S-Organic-Manure

# Open directly in browser
# Windows:
start index.html
# macOS:
open index.html
# Linux:
xdg-open index.html
```

Or serve via any static HTTP server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
